# Contribution-First Writing Guide

一份以贡献、优势和核心证据组织论文的中英文学术写作通用规范。

本指南帮助作者和 AI 写作助手减少重复辩解、自我削弱和过程流水账，让研究价值在摘要、引言、正文和结论中清楚呈现。适用于中文和英文的论文写作、稿件修订、图注和论文导向的报告。

## 六条写作原则

1. **围绕领先优势组织叙事。** 提炼独特价值，让核心证据支撑主线。
2. **选对战场。** 选择体现研究价值的任务、评价口径和应用场景。
3. **优势主动说清，从头讲到尾。** 明确说明优势出现的条件、来源和意义。
4. **实验服务于论证。** 每个正文实验和图表承担明确职责。
5. **不主动示弱。** 删除笼统自我评价、重复降调和无信息的自我设限。
6. **写成果逻辑。** 围绕最终成立的论证展开，并根据核心证据调整问题、贡献排序和文章结构。

允许先成文再补实验，待补实验集中记录。相容且未被现有证据否定的假设保留为工作假设，引入后用于推演。局限集中在讨论末尾，表述强度按实际证据确定。

默认读者能够正常理解语境，围绕实际问题直接说明事实、解释和判断，不预设误解或提前答辩。**如果某句话的作用只是防止被质疑，而不是推进论证，请删除。** 确实影响判断的条件直接写入具体陈述，避免换一种措辞继续保持防御姿态。

表达层面同时强调具体陈述、术语一致、合理的学术语体、明确的引用作用和作者风格。具体化使用已有材料，缺失证据集中待补；句子修改按功能判断，并遵循作者明确约定。

## 使用方法

完整规范见 [WRITING_GOALS.md](WRITING_GOALS.md)，包含贡献目标、章节职责、实验安排、修改方式和可复制的协作指令。

将指南放入研究项目，向写作助手说明当前任务。例如：

```text
请先阅读 WRITING_GOALS.md，再修改下面的论文文字。
围绕核心贡献和证据组织叙事，删除重复降调与防御性表达。
默认读者能够正常理解语境，不预先答辩。
如果某句话的作用只是防止被质疑，而不是推进论证，请删除。
删除不增加信息的套话和装饰性表达，保持术语与指代稳定，保留合理的学术语体，明确引用作用，并参考作者认可的样稿。具体化只使用已有材料，缺失证据列入内部待补清单。
先给可复制的修订文本，再简要说明必要的修改。
```

需要先诊断时，可以使用：

```text
请按 WRITING_GOALS.md 检查下面文字中的防御性写作。
逐处给出原文、问题和建议改法，先不修改全文。
```
